# Pablo's Patisserie – SEO-ready site

This version adds crawlable SEO pages and metadata for the Pablo's Patisserie baking game.

Pages:
- /
- /about.html
- /how-to-play.html
- /characters.html
- /recipes.html
- /updates.html

After pushing to GitHub Pages:
1. Confirm https://www.pablospatisserie.com/ loads.
2. Confirm /robots.txt and /sitemap.xml load.
3. Add pablospatisserie.com to Google Search Console as a Domain property.
4. Submit https://www.pablospatisserie.com/sitemap.xml.
5. Request indexing for the homepage and the new pages.

The CNAME remains www.pablospatisserie.com.
